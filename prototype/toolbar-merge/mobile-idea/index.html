手机 · 已有一条想法时怎么显示

点中一条有想法的划线，想法放哪儿？

四个独立的小原型，每个都只回答一个问题：想法出现在哪、以及**划线贴着屏幕上下边缘时**它怎么办。点开任意一版，用底部的「场景」切到 顶部 / 底部 / 长想法 看边缘表现。

四版的工具条、书摘 / AI / 写想法弹窗（带遮罩、居中偏上）都相同，只有「想法」的处理不同。

A 贴底卡片

想法钉在屏幕底部（底栏上方），宽度撑满，内容多了卡内滚动。工具条照旧贴着文字。

边缘永远不会和文字抢地方；代价是离划线远。划线本来就在底部时，正文会自动往上让一点，把那句话露出来。 B 工具条 + 想法整组翻边

想法紧跟工具条，两件东西叠成一组；整组按剩余空间放到划线下方或上方。

边缘贴顶就整组往下、贴底就整组往上；两边都不够时想法限高、卡内滚动。离文字最近，也最容易压住旁边的行。 C 收进工具条

正文上不出现想法卡片；「想法」按钮右上角一颗小点表示这条线有想法，点开是带遮罩的弹窗。

边缘没有任何边界问题——弹窗固定在中间偏上。代价是要点一下才看得到，想法容易被忘掉。 D 吸附条

想法做成一条贴在阅读区上缘（顶栏下方），只露三行，点开看全。

边缘划线靠上、会被条子压住时，条子自动翻到下面贴着底栏。位置固定、不压正文，但和划线的空间关系最弱。

四个文件各自独立，双击就能开；没有构建、没有依赖。
看完告诉我选哪一版（或者「A 的贴底 + C 的小点」这种拼法），我再落成定稿。
