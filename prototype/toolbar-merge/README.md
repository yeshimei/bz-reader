# 原型 · 划词工具条（定稿 v4）

**一次性原型，不是产品代码。** 这一版按评审结论重写，只剩一套布局，没有可切换的方案。

## 定下来的三条

1. **桌面 A 全平铺**：色点 ｜ 想法 书摘 AI 双链 复制（有划线时再加「删除」），全部摆在明面上。
2. **桌面浮窗全部在工具条上方**：想法气泡、想法输入、书摘、AI、删除确认，都叠在工具条**上方**挂着。
   工具条紧贴文字、位置固定——开面板时它不动，面板往上长。
3. **手机 B + 独立弹窗**：工具条只留主路径（想法 书摘 AI）+「⋯」，放不下的（双链 / 复制 / 删除）
   收进「⋯」；放不下主路径本身时，末尾的动作也会跟着收进去。面板不再跟着工具条：
   单独一张卡，水平居中、**偏上**（约阅读区 17% 的高度）。

## 打开

双击 `index.html` 即可（单文件，无外部依赖，纸/墨两套主题都在里面）。

- 正文里**拖选**一句话 → 工具条出现在选区上方（桌面）/ 下方（手机）
- **点一条已有划线** → 同一条工具条；当前色加圈、末尾多「删除」；有想法时浮窗自动出来
- 点 **想法 / 书摘 / AI** → 面板展开（桌面在工具条上方；手机是居中偏上的独立弹窗），工具条不收起
- 手机点「⋯」展开被收起的动作；菜单会自动朝空间大的那一侧开
- 点色点改色、点「删除」走确认、`Esc` 收起

底部控制条只有「桌面 / 手机」和一行状态（当前是划词还是点划线、面板是哪个、手机上收了哪些动作）。

## 两端的差异

|  | 桌面 | 手机 |
| --- | --- | --- |
| 工具条排布 | A 全平铺，不收起 | B 主次 + ⋯，放不下继续收 |
| 工具条位置 | 选区 / 划线**上方** 8px | 选区 / 划线**下方** 10px，放不下翻上去 |
| 面板 / 想法 | 叠在工具条**上方**，跟着工具条走 | **独立弹窗**，居中偏上，不跟工具条 |
| 开面板时工具条 | 不动 | 不动 |

## 文件

- `index.html` —— 原型本体（样式、交互、示意文本都在里面）
- `shot.mjs` —— 用 Edge headless 截关键状态到 `.shots/`
- `measure.mjs` —— 量工具条 / 浮窗 / 弹窗的盒子，确认位置关系
- `smoke.mjs` —— 把交互真点一遍（26 项：浮窗在上、工具条不动、弹窗居中偏上、⋯ 收得起……）

`.shots/` 每次截图随手生成，不进仓库。
