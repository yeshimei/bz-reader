### 安裝

在社群市集安裝（首次上架審核通過後可見）：

1. 開啟 **設定 → 第三方外掛**，關閉安全模式。
2. 點 **瀏覽**，搜尋 **bz Reader**，安裝。
3. 啟用後左側出現 bz 圖示，從書架開始。

審核期間或搜不到時，用 [BRAT](https://github.com/TfTHacker/obsidian42-brat) 加入本倉庫安裝，或手動下載 Release 裡的 `main.js`、`manifest.json`、`styles.css`，放進 `<你的庫>/.obsidian/plugins/bz-reader/` 後啟用。

### 介面語言

介面跟著 Obsidian 的語言走，也可以在 **書架 → 設定 → 介面** 裡手動指定：简体中文、繁體中文、English、日本語、Deutsch、Français、Español、Português。

切換後介面立即生效；指令名稱需重新啟動 Obsidian 才更新。繁體不是簡體的字形轉換，是另一套台灣用語（設定 / 預設 / 匯入 / 匯出 / 檔案）。**更新日誌是唯一的例外**：它每次發版手寫，只做中文與英文兩版，其餘六種語言顯示英文條目。

### AI 是如何運作的

- 每本書在本機維護一份**画像**（chunk + 向量 / 摘要）。
- 提問先做**問題路由**，再走**混合檢索**，只有預算內的依據會進入 prompt。
- 回答透過 SSE 串流回傳，接著做**引文回核**。

#### 為什麼嵌入要借 bz 算

- 外掛以三個檔案發布（`main.js` / `manifest.json` / `styles.css`），帶不走模型權重與推理執行環境；內建固定小模型等於把所有人的檢索精度鎖死。
- 嵌入層由 bz（第二大脑）提供，模型選擇權在你：本機大模型或雲端服務，算力越強可以上越重的模型，定位越準。
- 書與筆記必須共用同一個**向量空間**（筆記命中也是依據之一），模型名稱與 bz 不一致會**靜默錯配**。
- 模型名稱由 bz 注入並寫入画像，換模型時舊向量自動作廢；向量本身仍只存在本機 `portraits/`。

#### 画像與切塊

- `portraits/<書 id>.json`：`plan / model / dim / chunkChars / overlap / blocks[] / overview / guides / done`，每塊記錄 `chapter / vec / digest / summary / text`。
- 向量以 base64 **Float32Array** 存檔，餘弦相似度在本機計算，寫入採原子替換；查詢向量有 50 筆 **LRU** 快取。
- 切塊以段落為界、章首過半收口。
- **A 向量化**：每塊 1000 字、重疊 120 字、8 塊一批；**B 資訊壓縮**：每塊 8000 字，交給聊天模型壓成要點，不參與向量檢索。
- 全域單例，手機端禁用。

#### 混合檢索與重排

- **字面通道**：中文二字組 **BM25**（k1 1.2 / b 0.75），章名字段權重 ×2.5。
- **向量通道**：查詢改寫後近鄰召回，絕對門檻 0.2 / 相對門檻 0.6。
- **RRF 名次融合**（k = 60）：餘弦與 BM25 不同量綱，按名次合併而非正規化。
- **自適應收口**：floor 3 / ceiling 30 / rel 0.3 / abs 1e-4，依章去重。
- **鄰居擴充**：前 3 名候選的同章前後塊以 0.85 權重入池；**章首補償**保留命中章的第一塊。
- **預算**：top 6 / 8000 字；跨書語意搜尋每書 3 筆、全局 20 筆上限。

#### 結構路由、生成與回核

- **章級地圖**：一章一行摘要、節號補回真名、字面選章權重 3/1、序號硬匹配、零模型呼叫。
- **整章讀**：目錄:正文 3:7、單章至少 600 字、超預算截斷留痕；全書問題走 `bookSpread` 每章均勻取樣。
- **劇透門**：在目前章的最後一塊截斷並清空 overview，三條檢索路徑與追問補充段落共用，預設關閉。
- **prompt**：8000 字依據 + 最近 6 輪；引文用「」括起並註明章節。
- **SSE 串流**：`TextDecoder(stream:true)` 處理漢字跨訊框、以位元組間隔計時、80ms 節流更新 DOM、保留半截答案。
- **引文回核**：4–80 字以二字組覆蓋 ≥0.8 比對本次實際依據，短句逐字相同；來源最多 8 筆、可跳回原文。

#### 不建索引的純 AI 路徑

- 劃詞解釋 / 翻譯 / 摘要：只傳送選取範圍，摘要 ≤100 字、解釋 ≤120 字。
- 追問：原文 ≤2000 字 + 可選同書 3 塊 / 1200 字；查詢用「劃線前 120 字 + 本次問題」解決指代缺失。
- 側欄脈絡：單筆 1200 字、合計 6000 字上限。

### 掃描版 PDF 怎麼劃記與搜尋

- **OCR**：「識別掃描頁」選單提供辨識本頁 / 接下來 20 頁 / 整本 / 重試失敗頁；逐頁串行、每批 20 頁。走視覺模型或自建 / 區域網路 OCR 服務（手機端只能用前者）；整本按頁計費會先彈出確認。
- **結果**：一本書一個側車 JSON，預設放在庫內 `bz-reader/storage/ocr/<書 id>.json`（資料目錄可改）；原 PDF 一個位元組都不改。重開仍在、隨同步目錄走；失敗頁留下供「重試失敗的 N 頁」使用，沒有自動重試。
- **文字層**：辨識結果按行鋪成透明、可選取的文字層壓在掃描圖上。有行框的頁才能劃詞；只有文字沒有行框的頁可讀可搜，但不能劃。
- **劃記**：OCR 頁與一般 PDF 共用同一套劃線、四色筆、想法、雙向連結；錨點是「頁碼 + 文字層字元偏移」。沒有文字層的頁拖曳會變成矩形框選，仍可寫想法、掛雙向連結、匯出書摘圖，但框內引文要辨識過才有內容。
- **搜尋**：全庫字面搜尋與 PDF 內查找直接讀取側車 JSON，不必建索引；命中點開跳到對應頁，在透明文字層上畫矩形高亮，每頁最多 40 處；全庫命中 300 筆、同頁 50 筆上限。
- **語意搜尋**：要先建画像。画像正文來自逐頁取字，因此必須**先 OCR 再建画像**才搜得到新辨識的文字；之後才辨識的頁必須重建画像。檢索另要求画像已完成、嵌入模型與目前一致。語意命中沒有精確錨點，點開後用片段開頭再執行一次全文搜尋定位。

### 朗讀是如何運作的

- **取文字**：EPUB / TXT 取目前可見段落或整章；PDF 只能念目前頁的文字層，掃描頁要先 OCR，且沒有按章預先生成。
- **三種引擎**：系統語音（完全離線、不快取不預取）、線上語音（官方或 OpenAI 相容端點）、自建語音服務。朗讀設定與 AI 設定互相獨立；手機端強制走線上。
- **切句**：先區分旁白與對白，再按句末標點切分；單句目標約 240 字，過長在逗號、頓號等軟邊界回退，過短碎片併入前句，純符號不念。系統語音另按約 220 字切，最長 4000 字。
- **播放排程**：逐句合成、逐句播放，播完自動接下一句；預設預取 3 句（自建服務會盡量備整章），同時最多兩個請求在途；換位置時只作废旧請求，不中斷預取。審核拒絕的句子跳過，預取失敗靜默重試一次，其他失敗停下來並提供「繼續聽」。
- **快取**：以「書 + 引擎 + 模型 + 音色 + 文字」為鍵存在本機，命中只更新時間、不重複合成；預設上限 300 MB，可調到 2 GB。
- **高亮**：線上與本機朗讀把每一句映射回正文做頁面高亮，不依賴語音事件也不靠計時；不支援時退回覆蓋層。離線整章音訊用時間軸反查目前句，系統語音靠開始回呼。
- **預先生成**：整章音訊拼成一個檔案，另附逐句時間與位元組區間的清單；寫入採原子替換並讀回校驗。進度分排隊 / 合成 / 打包 / 完成 / 取消 / 失敗六態，不做時間預估，停止在句邊界生效；既有快取就是進度，可續做或重做。整章是進階版功能，整本僅本機引擎可用、手機不可用。
- **離線聽書**：把整個套件目錄（音訊 + 清單）放進庫內 `bz-reader/offline/`，外掛只掃一層，依書名、書 ID 依序識別；只拷 mp3 不會被發現，設定裡可「重新掃描」。逐句按清單切片播放，沒有區間就整章播放並按時間軸推高亮；正文改過會自動對齊，播完自動進下一章。
- **續聽**：只保留最近一筆，停止那一刻寫到本機；粒度是句。復原依「同章原位 → 全章查找 → 退回頁首」三級；換裝置不跟隨。

### 網路存取

只有 AI 功能與「支持作者」名單會連網，其餘功能完全離線。

- 請求發往你在設定裡填寫的 OpenAI 相容介面（自建服務或第三方 API 均可），外掛沒有自己的伺服器。
- 建全書索引時，整本書的正文會分塊發給嵌入服務；提問時只發檢索命中的那幾塊，必要時再帶上書名、章節名與最近幾輪問答。向量與索引都存在外掛目錄裡，不上傳。
- 嵌入由 bz（第二大腦）外掛提供：沒裝它就沒有向量檢索，只能走壓縮要點那一檔。
- API 金鑰與其他設定一起保存在外掛目錄的 `data.json` 裡，不會上傳給外掛作者；只有請求你自己填寫的那個介面時，它才會以請求標頭的形式送過去。
- 打開「支持作者」視窗（或更新日誌）時，會讀取一份公開的支援者名單：同時請求 GitHub 與碼雲上的同一個靜態 JSON，誰先回用誰。只取這一份名單，不發送任何個人資訊、不做統計上報；名單會快取在本機，兩個來源都不通時顯示「名單沒載入出來」和重試。名單是公開資料，內容與兩個外掛裡顯示的完全一致。

### 常見問題

- **支援哪些格式？** EPUB 與 TXT 開箱即讀；mobi、azw3、fb2、漫畫與 PDF 在高級版。
- **會和其他外掛衝突嗎？** 閱讀頁是 Obsidian 原生檢視，目錄是左側欄裡的一個頁籤；劃線可以複製成帶定位的 Markdown 連結，點一下跳回原文那一句，不另建索引。
- **換電腦怎麼辦？** 庫同步過去，書架、進度與標註跟著走；高級版在新裝置上重新填一次啟用碼。
- **手機上要單獨買嗎？** 不用，同一個包，桌面與行動都包含在內。
