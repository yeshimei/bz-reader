# 更新日志

## ✨ 新增

- **汇总范围** ：设置里给剪藏成书加了三选一：全部 / 未读 / 今日+未读，默认未读——每天翻开的都是还没读的部分。

## ⚡ 优化

- **看视频** ：功能对照里 AI 知识盒与剪藏成书两行带「看视频」，点开就是对应的教程。

# 安装

1. 打开 **设置 → 第三方插件**，关闭安全模式。
2. 点 **浏览**，搜索 **bz Reader**，安装。
3. 启用后左侧出现 bz 图标，从书架开始。
