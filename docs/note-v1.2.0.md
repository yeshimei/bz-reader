# 更新日志

## ✨ 新增

- **页码** ：阅读页右下角可以显示页码，关掉、只数本章、还是全书累计，自己挑。
- **章节名** ：沉浸模式左上角显示当前章节，也可以单独关掉。
- **点击翻页** ：桌面端点正文左右两侧就能翻页，默认关，触屏笔记本可以打开。

## ⚡ 优化

- **PDF 缩放** ：排版面板补上放大缩小，以及适合宽度、适合页面、实际大小。
- **PDF 面板** ：排版面板贴着按钮弹出，底栏改成卡片。

# 安装

1. 打开 **设置 → 第三方插件**，关闭安全模式。
2. 点 **浏览**，搜索 **bz Reader**，安装。
3. 启用后左侧出现 bz 图标，从书架开始。
