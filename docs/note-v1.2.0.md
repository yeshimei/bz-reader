# 更新日志

## ✨ 新增

- **页码** ：阅读页右下角可以显示页码，关掉、只数本章、还是全书累计，自己挑。
- **章节名** ：沉浸模式左上角显示当前章节，也可以单独关掉。
- **点击翻页** ：桌面端点正文左右两侧就能翻页，默认关，触屏笔记本可以打开。
- **PDF 缩放** ：排版面板补上放大缩小，以及适合宽度、适合页面、实际大小。
- **高级版** ：解锁弹窗照商品图重做，表头、整列底色和底部合计都补齐了。

## ⚡ 优化

- **两角小字** ：章节名与页码贴正文边缘、避开状态栏，字号跟着正文字号走。
- **头栏标题** ：显示当前章节，不再一直是书名。
- **桌面页码** ：可以挂进 Obsidian 状态栏，状态栏关掉时退回正文右下角。
- **PDF 面板** ：排版面板贴着按钮弹出，底栏改成卡片。
- **支持者** ：去掉手动刷新，打开弹窗就拉一次名单。

## 🐛 修复

- **手机头栏** ：恢复显示书名。
- **顶部留白** ：分页顶部空带收窄，标题跨栏居中，安全区不再叠两遍。
- **更新日志** ：版本行不再被按钮压扁，条目也不会串到下一版。

# 安装

1. 打开 **设置 → 第三方插件**，关闭安全模式。
2. 点 **浏览**，搜索 **bz Reader**，安装。
3. 启用后左侧出现 bz 图标，从书架开始。
