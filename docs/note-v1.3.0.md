# 更新日志

## ✨ 新增

- **剪藏成书** ：书架里多一本活书，内容直接读 bz 剪藏本，按订阅分卷；进章自动标已读，每章读了几分钟也记在里面。
- **生成摘要** ：读订阅文章时，头栏可以按篇生成 AI 摘要，写在标题下方；剪藏本更新后按文章迁回原来的位置。
- **bz 组** ：设置页把剪藏本和 AI 知识盒归到「bz」组，检测到 bz 才出现开关，两项各有自己的教程。

## ⚡ 优化

- **宽屏** ：每栏宽度跟着阅读区走，宽屏下不再两侧一片空白。

# 安装

1. 打开 **设置 → 第三方插件**，关闭安全模式。
2. 点 **浏览**，搜索 **bz Reader**，安装。
3. 启用后左侧出现 bz 图标，从书架开始。
