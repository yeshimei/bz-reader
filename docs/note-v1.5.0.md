# 更新日志

## ✨ 新增

- **扫描页识别** ：PDF 扫描页也能认字了。头栏「识别」可选本页、接下来 20 页或整本；认出来的文字直接进文字层，能划词、能搜索、能朗读，也能交给 AI。按页计费，认过的页会跳过。
- **识别通道** ：可以用 DeepSeek 看图，也可以填自己跑的服务（OpenAI 兼容、Umi-OCR、PaddleOCR）。设置里有「连接测试」，发一张小图就能确认地址与密钥对不对。
- **划词 AI** ：划一段文字弹出五项菜单：解释、翻译、总结、追问，或者丢进全书问答继续问。浮框锚在原文旁边，可以拖动、可以定住不关。
- **对话页** ：书架多了「对话」页，AI 问答按书或按时间翻，能搜、能归档，也能一键导出到阅读笔记。
- **连接笔记** ：侧栏问答可以带上笔记一起问，按目录分组、支持多选，也能全库搜。
- **加入复习** ：划好的句子或整章重点交给 AI，挑出值得长期记的，按全文回忆、抽认卡、做题三种方式制卡；装好 bz review 插件后直接进它的复习队列。

## ⚡ 优化

- **搜索** ：书架搜索页与弹窗重做，书名、章节、划线、正文分开列；字面与按意思两种搜法各归各位，扫到哪本、找到几处都写在脸上。
- **朗读** ：浮条补上进度与「继续听」浮窗；点一下就开始，不用再点第二次。
- **划词工具条** ：点一下展开，再点收合，不挡正文。

## 🐛 修复

- **PDF 识别** ：识别出来的文字按页框尺寸摆放，放大缩小后划线与文字不再错位。
- **朗读** ：没有可念文字时，朗读条不会留在屏幕上收不掉。

# 安装

1. 打开 **设置 → 第三方插件**，关闭安全模式。
2. 点 **浏览**，搜索 **bz Reader**，安装。
3. 启用后左侧出现 bz 图标，从书架开始。
