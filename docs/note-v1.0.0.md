# 更新日志

## ✨ 新增

- **PDF 阅读** ：PDF 成为第八种格式，文字版能选字、划线、搜索与朗读。
- **PDF 排版** ：缩放、旋转、单双页、缩略图与跳页，每本书记住自己的设置。
- **PDF 双链** ：页码、视图、嵌入与批注四种链接都能复制，兼容 PDF++ 与原生写法。
- **PDF 反链** ：看本页被哪些笔记引用，文件自带的批注也能标出来。
- **PDF 页图** ：当前页存成图片，扫描件也能留一张。
- **回到上一处** ：点目录或链接跳走之后，一键回原来的位置，EPUB 同样可用。
- **引用页签** ：高级版可用；笔记里指向本书具体位置的链接按书聚在一起，点一条回到原文那一句。
- **导出这本书** ：书卡右键直接导出整本摘录，每条摘录本身就是能点回原文的双链。
- **划线颜色** ：设置页里选默认笔色，和划词条上的色点用的是同一份。
- **支持作者** ：设置页顶部与更新日志页脚都能打开赞赏窗，附支持者名单。
- **赞助人身份** ：赞助码的徽章改用买家昵称，设置页另外标出「赞助人」。
- **高级版对照表** ：新增「PDF 阅读」一段，引用页签归入高级版并排在双向链接下面，书摘图片下放基础版，行名与界面用词对齐。

## ⚡ 优化

- **全库搜索** ：每本先列 50 条并注明已显示多少，打不开的书单独列一行。
- **划词工具条** ：图标模式松开一档间距，双链、存为名词、存为段落点完就落线，笔色记住上次选择。
- **链接别名** ：设置里收成三档文字，不再留一档藏在面板里的图标。
- **更新日志** ：底栏改版，版本行留出行距。
- **支持弹窗** ：跟随设置页的强调色，手机端贴底并避开安全距。
- **书摘图片** ：基础版也能把划线复制成图片，图片一律带 bz reader 徽章。
- **权限调整** ：引用页签这版起归入高级版，与双向链接共用一道门禁；书摘图片反过来下放基础版，两版都能复制。
- **升级说明** ：从 0.4.1 跨到 1.0.0 只是版本号变化，数据格式没动：旧库直接升级，书架、进度、标注与设置原样保留。

## 🐛 修复

- **PDF 白屏** ：Obsidian 内核较旧时打开 PDF 不再白屏。
- **PDF 划词** ：有文字层的页默认走划词，框选退到 Shift 加拖动。
- **PDF 错位** ：缩放之后划线、反链与搜索命中不再整体偏移。
- **PDF 搜索** ：全库搜索能搜到 PDF 正文，跳过去也会标出关键词。
- **PDF 批注** ：文件自带的标注不再丢颜色与批注正文。
- **PDF 词间距** ：带字距的词不再被空格撕开。
- **PDF 页溢出** ：窄栏与手机首屏不再被裁掉一截。
- **设置徽章** ：三种码各显示各的，赞助人码也保留高级版徽章。
- **长想法** ：再长也不会把侧栏顶出一条横向滚动条。

# 安装

1. 打开 **设置 → 第三方插件**，关闭安全模式。
2. 点 **浏览**，搜索 **bz Reader**，安装。
3. 启用后左侧出现 bz 图标，从书架开始。
