# 更新日志

## ⚡ 优化

- **设置页** ：长分组切出小标题（文字 / 页面 / 阅读 / 导出与链接 / 目录 / 排查），图标改双列排、引擎卡补上图标，一屏之内更好找。
- **按意思搜** ：搜之前先用 AI 把你那句口语压成检索词，去掉「哪本书」「讲过」这类问句壳，向量更准；字面通道仍用原话，书名、年份、引文不丢。AI 没配好或临时失败就按原话搜，不影响正常使用。

## 🐛 修复

- **补全信息** ：只识别到语言时如实说「简介和分类这次没补上」，不再弹「已补上简介与分类」却一个字没变。

# 安装

1. 打开 **设置 → 第三方插件**，关闭安全模式。
2. 点 **浏览**，搜索 **bz Reader**，安装。
3. 启用后左侧出现 bz 图标，从书架开始。
