# 更新日志

## ✨ 新增

- **AI 服务商** ：内置 18 家 AI 服务商，挑一家填上密钥就能用，也能自己填地址和协议。 [QQ 频道 ↗](https://pd.qq.com/s/Na2zwqz6c1)
- **复习页签** ：装了 bz Review 后，书架多一个「复习」，挑内容、制卡、复习都在一起。
- **统计回顾** ：统计页重做成六块——概览、时间、书、笔记、成就、数据。
- **字数与速度** ：算出读过多少字、读得多快，还能按近 7 天、30 天、一年分开看。
- **成就徽章** ：连续阅读、读完多少本、深夜读书……攒满 18 枚徽章。
- **换版本不串线** ：同一本书换了新版本，旧进度自动归档，书架「已归档」里随时能找回来，新版本从头开始读。 [QQ 频道 ↗](https://pd.qq.com/s/N63q5vnx8b)
- **下载有备份** ：插件下载连不上 GitHub 时自动换码云，点一下就能下。

## ⚡ 优化

- **加入复习** ：划线加入复习后显示「已在复习」，确认时顺手补一条划线，不用再划一次。
- **制卡流程** ：挑完内容后的制卡界面整段交给 bz Review，能先看到题面再决定留不留。
- **更新日志** ：统计数字改成随版本固定，反馈列表同时显示两个插件的条目，手机上工具条铺满一行。
- **按章节** ：弹窗固定半屏高，章节列表单独滚动，头尾按钮不再被长列表推走。
- **手机书架** ：四颗图标收进三点菜单，窄屏头栏不再挤成两行。
- **AI 提示** ：没配置 AI 时不再只弹一句提示，给一个能直接跳到设置页的窗口。

## 🐛 修复

- **手机侧栏** ：从侧栏跳转后自动收起，不再挡着正文。 [QQ 频道 ↗](https://pd.qq.com/s/N881m4ojyd)
- **复习杂项** ：补题只补一道，划线后清选区，弹窗关掉即取消在途请求。
- **取消与朗读** ：AI 问答中途取消立刻停住；听书切句时旧回调不再盖住新句子。
- **路线图** ：只显示 Reader 自己的条目，长分组平铺不折叠。

# 安装

1. 打开 **设置 → 第三方插件**，关闭安全模式。
2. 点 **浏览**，搜索 **bz Reader**，安装。
3. 启用后左侧出现 bz 图标，从书架开始。
