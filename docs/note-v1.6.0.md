# 更新日志

## ✨ 新增

- **AI 服务商** ：内置 18 家 AI 服务商，挑一家填上密钥就能用，也能自己填地址和协议。 [<sub>QQ 频道反馈</sub>](https://pd.qq.com/s/Na2zwqz6c1)
- **复习页签** ：装了 bz Review 后，书架多一个「复习」，挑内容、制卡、复习都在一起。
- **统计回顾** ：统计页重做成六块——概览、时间、书、笔记、成就、数据。
- **字数与速度** ：算出读过多少字、读得多快，还能按近 7 天、30 天、一年分开看。
- **成就徽章** ：连续阅读、读完多少本、深夜读书……攒满 18 枚徽章。
- **全书鸟瞰** ：下放到基础版，免费用户也能用。

## ⚡ 优化

- **换版本不串线** ：同一本书换了新版本，旧进度自动归档，书架「已归档」里随时能找回来，新版本从头开始读。 [<sub>QQ 频道反馈</sub>](https://pd.qq.com/s/N63q5vnx8b)
- **手机书架** ：四颗图标收进三点菜单，窄屏头栏不再挤成两行。
- **AI 提示** ：没配置 AI 时不再只弹一句提示，给一个能直接跳到设置页的窗口。

## 🐛 修复

- **手机侧栏** ：从侧栏跳转后自动收起，不再挡着正文。 [<sub>QQ 频道反馈</sub>](https://pd.qq.com/s/N881m4ojyd)
- **取消与朗读** ：AI 问答中途取消立刻停住；听书切句时旧回调不再盖住新句子。

# 安装

1. 打开 **设置 → 第三方插件**，关闭安全模式。
2. 点 **浏览**，搜索 **bz Reader**，安装。
3. 启用后左侧出现 bz 图标，从书架开始。
