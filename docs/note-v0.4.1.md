# 更新日志

## ⚡ 优化

- **高级版对照表** ：按阅读与书架、格式与导出、统计与检索、AI、进阶分成五段，勾选列统一居中，段题前不再有竖条。
- **目录页签** ：去掉名字后面的计数。
- **书签与划线** ：侧栏里改用实心铜点，和正文的强调色对上。

## 🐛 修复

- **长想法** ：再长也不会把侧栏顶出一条横向滚动条。

# 安装

1. 打开 **设置 → 第三方插件**，关闭安全模式。
2. 点 **浏览**，搜索 **bz Reader**，安装。
3. 启用后左侧出现 bz 图标，从书架开始。
