# 更新日志

## ⚡ 优化

- **朗读语言** ：按书的语言挑发音，英文按句号断句，不再一页念成一句。
- **弹窗读屏** ：弹窗补上读屏标签与焦点圈闭，键盘 Tab 不会跑出窗。
- **翻页方向** ：点按、键盘、拖拽共用一条规则，从右往左的书不再翻反。
- **手势** ：删掉双指捏合与 Ctrl+滚轮改字号，不再和系统缩放抢同一只手。
- **书架重绘** ：内容没变不再整页重画，封面墙翻起来更顺。

# 安装

1. 打开 **设置 → 第三方插件**，关闭安全模式。
2. 点 **浏览**，搜索 **bz Reader**，安装。
3. 启用后左侧出现 bz 图标，从书架开始。
