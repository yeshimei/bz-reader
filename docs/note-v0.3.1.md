# 更新日志

## ✨ 新增

- **第二大脑书单** ：bz 的「第二大脑」能读到书架清单，从那边直接点开一本书。
- **恢复确认** ：从备份恢复会先摊开说明再执行，点错也有一步回头。
- **朗读语言** ：按书的语言挑发音，英文按句号断句，不再一页念成一句。
- **弹窗读屏** ：弹窗补上读屏标签与焦点圈闭，键盘 Tab 不会跑出窗。

## ⚡ 优化

- **解锁弹层** ：购买条与激活框钉在底部，对照表再长也够得着。
- **翻页方向** ：点按、键盘、拖拽共用一条规则，从右往左的书不再翻反。
- **手势** ：删掉双指捏合与 Ctrl+滚轮改字号，不再和系统缩放抢同一只手。
- **书架重绘** ：内容没变不再整页重画，封面墙翻起来更顺。
- **迁移** ：重复点「开始迁移」不会把同一批文件搬两遍。
- **搜索** ：中途换词或关书，上一轮的结果不会闪回来。

## 🐛 修复

- **删除** ：书签与划线按它自己那本书找，切过 tab 也不会删错。
- **恢复** ：旧备份恢复不再抹掉本机的字号与行距。
- **授权** ：验签环境异常时明确提示，不再静默降成未激活。
- **同步** ：不再替你做跨设备合并，谁最后写谁赢；要合并请用你自己的同步工具。
- **Esc** ：宿主弹窗开着时让给它，不会关错那一层。

# 安装

1. 打开 **设置 → 第三方插件**，关闭安全模式。
2. 点 **浏览**，搜索 **bz Reader**，安装。
3. 启用后左侧出现 bz 图标，从书架开始。
