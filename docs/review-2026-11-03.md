## 二、代码 review

### P0 —— 会直接让「改好了」这句话不成立

**P0-1 排版浮层的三个滑块没有接线**
`OverlayLayer` 只处理了 `searchkw` 的 input（`overlay.ts:837-847`），整个浮层没有 `dispatchInput` / `change` 兜底。`data-role="pref"` 的 range 拖了不触发 `setPref`，年度目标的 range（`overlay.ts:533`）同样死。
修法：在 `this.root` 上加 `input`/`change` → `if (t.dataset.role) dispatchInput(t)`，与 `shelf-panel.ts:124-130`、`side-view.ts:93-99` 一致（这两处已经有，只有浮层漏了）。

**P0-2 封面链路整条断的**
`coverUrl(app, book)`（`data/cover.ts:146`）无人调用；`adapt.ts:118` 读的 `meta.coverPath` 无写入点。新书架 100% 出哈希色块。`overlayDetail` 还硬编码 `coverUrl: null`。
修法：`ShelfPanel.render()` 里对 `toRows` 结果异步补封面（拿到 objectURL 后只改对应 `img`，不要整页重绘），详情页复用同一份。

**P0-3 测试是红的**
`tests/license.test.ts:47`、`:54` 仍断言 `BZR2` 应被拒绝，而 `parseLicense` 已接受 v2。门禁（`pnpm test`）现在过不去。要么改断言（推荐，v2 是新格式），要么回滚解析。

**P0-4 目录编号还在**
`sidebar.ts:68` 的 `<span class="no">` 就是用户点名要去掉的那一列。去掉之后 `t` 列能多出约 20px，正好是「尽可能多展示内容」。

**P0-5 两本书时，关一本会清掉另一本的目录**
`settle()` 无条件 `clearToc()`（`reader-view.ts:1157`）。两个阅读 tab 时关掉 A，B 的侧栏立刻变空态，要等 B 下一次翻页 relocate 才恢复。
修法：`settle()` 里判断 `getToc()?.bookId === this.bookId` 再清；或让 toc-state 支持「按 bookId 存多份」。

## 三、你问的「不和 Obsidian 主题冲突的前提下，还能设置什么外观」

原则：**颜色一律不碰**（都由宿主变量来），只开放「排版度量」和「装饰开关」。这样换主题、换明暗都不会出现一块异色。

现在能设的：强调色（5 档）、字体（跟随书籍/宋/黑）、字号、行距、页边距、对齐、方向（横/竖）、栏数、脚注模式。

可以加、且不会跟主题打架的：

1. **版心宽度**（每行字数 30–45）：比页边距更符合阅读直觉，长行是 EPUB 阅读疲劳的头号原因
2. **首行缩进**开/关（中文 2em，西文 0）
3. **段间距**：0 / 半行
4. **字距**（0 / 0.015em / 0.03em）
5. **标点挤压 / 避头尾**（`text-spacing-trim`、`line-break: strict`）：中文排版的正经开关
6. **章题装饰**开/关（h1 下面那条 34px 强调色短线）
7. **首字下沉**开/关（现在写死开）
8. **页眉页脚**：书名 / 章节名 / 页码，各自开关
9. **图片处理**：暗色下反色（现在写死开）、最大宽度（100% / 版心）
10. **划线透明度**（浅色 0.42 / 深色 0.34 现在写死）
11. **双栏栏间距**
12. **竖排时的列距**（和行距分开，竖排里「行距」其实是列距）
13. **正文字体与标题字体分开**（标题常想用黑体、正文用宋）
14. **阅读区左右留白**在宽屏下的上限（现在 `margin` 直接当 padding，宽屏一行会拉到 1200px）

不建议加的：任何「纸色 / 背景色 / 文字色 / 边框色」——那就是把宿主主题撕开一个口子，之前五套皮肤就是这么翻车的。
