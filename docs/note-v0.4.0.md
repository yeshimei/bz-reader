# 更新日志

## ✨ 新增

- **分类管理** ：书架分类可以新建、改名、排序、删除，空分类也留得住。
- **归入分类** ：书卡菜单里直接挑一个分类，名字后面跟着本数。
- **统计页** ：时长、趋势、节律、目标与打卡、书籍明细、口径对照，整页重做。
- **想法气泡** ：划线旁的想法带「想」字印，长想法限高可滚，点开看全文。
- **知识盒链接** ：存过名词或段落的划线多一枚可点的链接。
- **书名开目录** ：点头栏书名直接打开左侧目录。
- **调试日志** ：设置里可开启，记录触摸、选区与翻页，可一键复制。

## ⚡ 优化

- **分类条** ：换成圆形筛选的语汇，顺序按自己排的来，书自带的分类接在后面。
- **划词条** ：新增图标模式，存过的名词与段落单独成链接，动作点完自动收选区。
- **手机分类弹窗** ：改成居中卡片，键盘弹起不再把卡片压成一条缝。
- **想法输入框** ：三行起，按内容撑高，长想法不用挤在一行里。
- **圆钮与图标** ：统一大一号，宿主压掉的底色补回。
- **设置页** ：备份说明紧跟备份行，调试项只留一句提示。

## 🐛 修复

- **分类删不净** ：移出书架的书还带着旧分类，重启后那一格又冒出来。
- **今天统计** ：切到「今天」时「每 1%」整列跌成几十秒。
- **图标模式误触** ：手机上按钮只有一道指宽，容易点到旁边那颗。
- **划词闪动** ：拖选时正文横移、高亮忽大忽小，已恢复稳定。
- **书摘印章** ：书摘展示窗去掉「bz 阅读」印章。

# 安装

1. 打开 **设置 → 第三方插件**，关闭安全模式。
2. 点 **浏览**，搜索 **bz Reader**，安装。
3. 启用后左侧出现 bz 图标，从书架开始。
