# 更新日志

## ✨ 新增

- **双向链接** ：划线可以复制成 `[[书#定位|原文]]` 双链，点一下跳回那一句，反链面板里也看得见。
- **多语言** ：界面支持中文、繁體中文、English、日本語、Deutsch、Français、Español、Português 八种语言，可跟随 Obsidian 或手动选择。
- **划词工具条** ：划词和点划线合并成同一枚工具条，复制、AI、双链都在一处。
- **阅读页图标** ：头栏图标扩到十项，可在设置里排序、收起，收起的进「⋮」菜单。
- **关于条** ：设置页顶部新增关于条，版本、GitHub、视频教程、交流群与更新日志收在一处。
- **更新日志** ：升级后第一次打开书库时自动弹一次。

## ⚡ 优化

- **基础版** ：单栏 / 双栏下放基础版，不再需要激活码。
- **删除划线** ：桌面改成贴字确认条，不再弹大卡。
- **书库** ：头栏文字与图标放大一档，桌面排序拆成三颗平铺。
- **设置** ：分组重新排序，阅读页图标移到外观之前。
- **强调色** ：从 5 档扩到 8 档，第一档叫「跟随 Obsidian」。
- **朗读** ：语速与朗读跟随从排版浮层搬到设置页，单独成组。

## 🐛 修复

- **阅读页** ：打开书不再自动展开侧栏与目录。
- **阅读页** ：导入后立即显示作者，滚动模式读完一章自动进下一章。
- **阅读页** ：重启后版式读本平台那一份，不再串到另一套。
- **手机** ：想法 / 书摘弹窗不再被输入法遮挡，正文底部让出安全区。
- **书库** ：筛选行不再被误判成手机，按窗口宽度摊开。
- **目录迁移** ：三个目录选择器恢复正常，迁移失败会回滚。
- **AI 输入框** ：输入期间不再落盘，打一个字不会失焦。
- **文件** ：不再抢 `.txt` 扩展名。
- **备份** ：备份与恢复同时带上桌面与手机两套版式。

# 安装

1. 打开 **设置 → 第三方插件**，关闭安全模式。
2. 点 **浏览**，搜索 **bz Reader**，安装。
3. 启用后左侧出现 bz 图标，从书架开始。
