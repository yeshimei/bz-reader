# 更新日志

## ⚡ 优化

- **书架头栏** ：进搜索、导入、统计、设置不再换头栏，页签和四颗图标一直在。
- **返回** ：再点一次亮着的那颗图标，就回到进来之前那一页。

## 🐛 修复

- **iPhone 翻页** ：章节正文重新允许脚本，点按与滑动恢复响应。
- **首装读盘** ：iPhone 第一次打开不再误报读取失败。

# 安装

1. 打开 **设置 → 第三方插件**，关闭安全模式。
2. 点 **浏览**，搜索 **bz Reader**，安装。
3. 启用后左侧出现 bz 图标，从书架开始。
