# 更新日志

## ⚡ 优化

- **搜索合并** ：本书与全库两档，书名、章节、标注与正文一次搜完。
- **搜索高亮** ：结果里的关键词加底色，没作者的书只显示书名。
- **搜索浮层** ：关掉再打开，还停在原来的词、结果和位置。

## 🐛 修复

- **移动端滑杆** ：设置页往下滚，手指扫过滑轨不再改字号与行距。

# 安装

1. 打开 **设置 → 第三方插件**，关闭安全模式。
2. 点 **浏览**，搜索 **bz Reader**，安装。
3. 启用后左侧出现 bz 图标，从书架开始。
