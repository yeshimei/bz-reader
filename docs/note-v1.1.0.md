# 更新日志

## ✨ 新增

- **按意思搜** ：书架和书里都能按意思找，不用先想到原话。
- **本章导读** ：读的时候点一下，先看这一章该带着什么读。
- **问这摞书** ：勾几本一起问，答案标明出自哪一本。
- **主题书单** ：给一个主题，找出相关的书并排成一条阅读路线。
- **AI 追问** ：对着一段话接着问，答案能存进想法。
- **对话存档** ：侧栏聊完，整段存成一篇笔记。
- **补全信息** ：书卡菜单一下补齐简介与分类。

## ⚡ 优化

- **PDF 翻页** ：翻页方式与单双页归 PDF 自己管，打开就是连续滚动。
- **AI 设置** ：第一个框改叫「接口地址」，填的就是地址本身。
- **扫描件** ：打开扫描版 PDF 不再先弹一句提醒。
- **设置页** ：阅读页图标挪到页尾，紧挨快捷键。
- **支持作者** ：两个出口并成一行。

## 🐛 修复

- **追问** ：刚发出的那句马上显示，答案按 Markdown 排版，底部按钮不会被滚走。
- **补全信息** ：信息齐了不再多问一次模型，点了先应一声。
- **PDF 双指** ：两指轻按真的切得动沉浸，划词后的点击不再误跳页。

# 安装

1. 打开 **设置 → 第三方插件**，关闭安全模式。
2. 点 **浏览**，搜索 **bz Reader**，安装。
3. 启用后左侧出现 bz 图标，从书架开始。
