# 更新日志

## ✨ 新增

- **全书问答** ：在侧栏就能就整本书提问，回答附上出处，点一下跳到那一章。
- **全书索引** ：每本书单独建一份索引，向量化检索或 AI 信息压缩两种建法任选。
- **知识盒** ：划词条里多出「存为名词 / 存为段落」，存进 bz 知识盒并回写双链。
- **文件失联** ：书文件被移走时书卡打上角标，点一下重新定位。
- **沉浸提示** ：进入沉浸模式时提示退出方式，桌面按 ESC、手机双指轻按。
- **书卡直达** ：点书卡直接进阅读，不用再点一次「继续」。

## ⚡ 优化

- **书架去重** ：同一份文件改名、换目录、复制一份，都只留一条记录。
- **移除书库** ：改成移出书架，进度、划线、想法全留着，重新导入就接上。
- **划词条** ：去掉与「问 AI」重复的翻译入口。
- **手机** ：正文上下留白收窄，底部不再重复让出安全区。
- **目录** ：点目录时自动切到目录页签并顶到前面。
- **群入口** ：解锁弹层里的加群按钮常驻，文案统一成「QQ交流群」。
- **AI 卡片** ：关掉卡片就停掉请求，不会在后台跑完照扣费。

# 安装

1. 打开 **设置 → 第三方插件**，关闭安全模式。
2. 点 **浏览**，搜索 **bz Reader**，安装。
3. 启用后左侧出现 bz 图标，从书架开始。
