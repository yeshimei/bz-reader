# 更新日志

## ✨ 新增

- **编辑书籍信息** ：书名、作者和简介都能改，封面可上传替换，也能还原原版。
- **划线排序** ：侧栏划线多了一档按原文排，默认仍按添加时间。 [QQ 交流群反馈 ↗](https://pd.qq.com/s/Nfwv9yibo1)
- **右键加书架** ：文件浏览器里右键点书，直接加入或移出书架。

## ⚡ 优化

- **更新提示** ：新版本提示改成书架顶部一条细条，补上市场、GitHub 和忽略三个出口。
- **导入折叠条** ：导入页已加入的书收进底部折叠条，主列表默认只列没加的。
- **归档书删除** ：已归档的书可以直接彻底删除，不再弹空的「移出书架」。
- **设置门牌** ：Obsidian 设置页加了 bz reader 入口，点一下进书架设置页。

## 🐛 修复

- **书架空态** ：空态不再吞掉筛选栏，「已归档」也回得去了。 [QQ 交流群反馈 ↗](https://pd.qq.com/s/N1etlo45j5)

# 安装

1. 打开 **设置 → 第三方插件**，关闭安全模式。
2. 点 **浏览**，搜索 **bz Reader**，安装。
3. 启用后左侧出现 bz 图标，从书架开始。
