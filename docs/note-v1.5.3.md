# 更新日志

## ✨ 新增

- **多分类** ：一本书可以同时归进好几个分类，菜单里点一下加进去、再点一下移出来。 [QQ 频道 ↗](https://pd.qq.com/s/N6x7xw49wb)
- **点图放大** ：书里的图片点一下就放大看，能缩放、拖动、复制和保存，设置里默认关。 [QQ 频道 ↗](https://pd.qq.com/s/Nh4jwljprw)
- **导出书摘** ：导出的书摘末尾多了一节「阅读记录」，把阅读时长和每次会话一起带走。 [QQ 频道 ↗](https://pd.qq.com/s/N1q1ho0cah)
- **导出书摘** ：每条划线下面写上了它是什么时候划的。 [QQ 频道 ↗](https://pd.qq.com/s/Na9tej9j6e)
- **彻底删除** ：移出书架时可以选择「彻底删除」，连记录和阅读数据一起清掉，源文件不动。 [QQ 频道 ↗](https://pd.qq.com/s/Na3wjeh5qo)
- **阅读统计** ：阅读会话开始记录中断次数。 [QQ 频道 ↗](https://pd.qq.com/s/N2ck4oj9ns)
- **字体** ：字体多了一档「跟随 Obsidian」，跟宿主主题走。 [QQ 频道 ↗](https://pd.qq.com/s/Neuwcw2kkt)
- **更新日志** ：更新日志弹窗重做，正文可在「更新 / 路线图 / 反馈」之间切换。

## 🐛 修复

- **加入复习** ：推给 Review 的划线卡带上跳回书里的链接。

# 安装

1. 打开 **设置 → 第三方插件**，关闭安全模式。
2. 点 **浏览**，搜索 **bz Reader**，安装。
3. 启用后左侧出现 bz 图标，从书架开始。
