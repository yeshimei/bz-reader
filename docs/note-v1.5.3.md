# 更新日志

## 🆕 新增

- **多分类** ：一本书可以同时归进好几个分类：分类菜单里每一格都能点，点一下加进去、再点一次移出来。原来的主分类仍按第一格写回，旧数据照常显示，不用重新整理。
- **点图放大** ：书里的图片点一下就放大看：滚轮缩放、按住拖动，可以复制、保存，装了 bz 还能顺手存成图版。设置里默认关，要用自己打开。
- **导出书摘** ：导出的笔记最后多了一节「阅读记录」——首次打开、最近阅读、累计时长、读完日期、每章花了多久，以及每次会话读到了哪一章、百分之多少。换库或迁移时，读书时间一起带走。
- **导出书摘** ：每条划线下面现在写着它是什么时候划下来的，不再只用来排章节顺序。
- **彻底删除** ：移出书架的弹层里新增「彻底删除」，输入书名确认后，这本书的记录与阅读数据一起清掉。书籍源文件和已经导出的书摘笔记不动，但笔记里指向它的双链会断。
- **阅读统计** ：阅读会话开始记中断次数（离开再回来算一次，一直挂着不算），随会话保存，也会写进导出的阅读记录。
- **字体** ：字体档里多了一档「跟随 Obsidian」：书页直接用宿主主题的字体栈，换主题或改字号不用再单独调一遍。
- **更新日志** ：插件里的更新日志重新做了一版：正文可在「更新 / 路线图 / 反馈」之间切换，反馈条目写着来自哪个群、核查结论和发布版本；手机上切 tab 就把正文换掉。

## 🐛 修复

- **加入复习** ：推给 Review 的划线卡现在带上一条跳回书里的链接，复习时能直接定位到那一句。

# 安装

1. 打开 **设置 → 第三方插件**，关闭安全模式。
2. 点 **浏览**，搜索 **bz Reader**，安装。
3. 启用后左侧出现 bz 图标，从书架开始。
