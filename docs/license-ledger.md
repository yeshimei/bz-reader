## 规矩

- 序号只增不减，**不复用**——发过、删掉、标 revoked 的号都不再分配。
- 新批次从台账 `nextSeq` 起连续签，签完自查：id 不重复、码不重复、序号不空号。
- 发现某枚码被公开传播：爱发电那边删掉对应行止血，台账里把这枚标 `revoked`，号**不回收**。
- 插件是**离线验签 + 在线停用名单**（2026-11-22 起，见下）。台账是「发过什么」的唯一事实来源，别只靠记忆。

## 停用名单

插件激活时核对一次，之后每次启动后台再拉一次；命中就降基础版，但**不删码**——解封后下次启动自动恢复。

```powershell
node scripts/revoke-license.mjs --id BZR-AF-2026-0021        # 停用
node scripts/revoke-license.mjs --unrevoke BZR-AF-2026-0021  # 解封
node scripts/revoke-license.mjs --code "BZR2...."            # 老码（BZR1 没有码号，按摘要封）
node scripts/revoke-license.mjs --list
```

改完自己 push，再跑 `node scripts/push-gitee.mjs --code` 镜像码云——**少推一条通道，就有一半用户拉不到名单**。

几条规矩：

- 名单里只有**码号**，不写码原文：`docs/revoked.json` 是公开文件。
- `updatedAt` 只增不减：插件拿它防重放，回退版本会让已封的码复活。
- 码号必须在 `ledger.json` 里出现过，脚本会挡；同一码号签过两枚码时也会拒绝，先查清再封。
- 第一次激活必须联网核对；已经激活的用户，拉不到名单时照常可用（离线优先）。
- 封一枚码不影响同一个人的其它码。

## 签发命令

```powershell
# 普通批次码：不署名，插件徽章写「赞助人」
node scripts/issue-license.mjs --plan lifetime --patron --id BZR-AF-2026-0175

# 定制昵称码：加群报名字后逐枚签，插件徽章直接显示昵称
node scripts/issue-license.mjs --plan lifetime --patron --name 小明 --id BZR-AF-2026-0175
```

`--plan lifetime` + 不传 `--days/--until` = 永久（payload 无 `exp`）。
`--patron` 让插件在「关于」条画赞助人徽章；带 `--name` 时徽章文字换成昵称。
定制码占同一号段，签完同样要更新 `ledger.json` 与上表。

## 试用码（群里发的那种）

试用码是**短期码**：`plan: trial` + 到期时间。跟付费码是两条线。
**码里不写版本**（2026-11-22 口径）：插件启动时拿线上最新版比，不是最新版就不解锁；
更新到最新版后自动恢复，不用换码。

```powershell
# 7 天试用
node scripts/issue-license.mjs --preset 7d --name "QQ群试用 11 月" --id BZR-TR-2026-11-01

# 固定截止日（当天 23:59:59 到期）
node scripts/issue-license.mjs --plan trial --until 2026-12-31 --id BZR-TR-2026-11-02

# 已过期的演示 / 测试码：签出来就该被拒
node scripts/issue-license.mjs --preset expired --id BZR-TR-TEST-01
```

几条规矩：

- **号段独立**：`BZR-TR-` 开头，单独流水，不占付费码的连续序号；不给 `--id` 时脚本自动用这个前缀。
- **7 天从签发时刻算死**，不是从激活算——重装 / 清数据都不能重新拿 7 天。代价是
  码在群里放两天再领只剩五天，发码时按批次现签。
- **必须最新版**：线上发布新版本后，旧版上的试用码会锁高级功能，但**码保留**；
  设置页会写「这枚试用码要求最新版（vX），当前 vY · 请先在设置里更新插件」。
- **离线**：24 小时内的最新版缓存直接用；缓存过期会重拉；从没拿到过最新版就锁，
  并提示联网确认。拉不到时**回退上次拿到的版本**，不让一次网络抖动锁死已激活的码。
- **永久码与赞助人码一律不看版本**，这是脚本与运行期共同的硬口径。
- **整批封**：群里共用一枚码时，用同一个 `--id` 签一批、台账记一行；传播失控就把这个
  id 写进 `docs/revoked.json`，整批一起停。
- **到期日**在签发摘要里会打出来（stderr），发群前核对一遍再贴。
