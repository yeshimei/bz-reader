# 更新日志

## ⚡ 优化

- **手机设置** ：分栏、朗读、快捷键收起来，头栏和菜单也不再出现这几项。
- **设置页** ：两列重新分档，朗读挪到 AI 上方，图标表每行补上同款图标。
- **默认版式** ：新装默认 26px 字号、1.7 行距、8px 边距，手机上一屏读一段。

# 安装

1. 打开 **设置 → 第三方插件**，关闭安全模式。
2. 点 **浏览**，搜索 **bz Reader**，安装。
3. 启用后左侧出现 bz 图标，从书架开始。
