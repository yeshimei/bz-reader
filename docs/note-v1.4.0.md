# 更新日志

## ✨ 新增

- **朗读** ：EPUB、TXT 与 PDF 都能念。整章一段脚本，念到屏幕外自动翻页；起播是这一页的第一个字，高亮跟着文字走，翻页、缩放、双栏与深色模式都不跑偏。
- **朗读方式** ：系统语音、DeepSeek 在线语音、或自己电脑上跑的 OpenAI 兼容服务（如 CosyVoice）三选一；在线也能填别家的兼容接口。
- **离线听书** ：预生成时把每章拼成一个 mp3，连同逐句时间轴存进库里的 bz-reader/offline。拷到手机或别的库，不连网也能听，高亮照常。
- **书库多选** ：书库可以多选，批量归入分类或移出书架；移出只是从书架拿走，进度、划线、书签与想法都留着。

# 安装

1. 打开 **设置 → 第三方插件**，关闭安全模式。
2. 点 **浏览**，搜索 **bz Reader**，安装。
3. 启用后左侧出现 bz 图标，从书架开始。
